Backup Escritorio

Ferramenta de uso privado administrada por Samuel Guilherme Martins para manter cópias de documentos do escritório no Google Drive, tendo o Microsoft OneDrive como origem.

Funcionamento

A transferência é executada pelo Rclone no computador do responsável. A autorização do Google permite criar e atualizar os arquivos da cópia de segurança gerenciados pelo aplicativo.

Este site é apenas informativo. Não recebe documentos, senhas ou tokens de acesso.
